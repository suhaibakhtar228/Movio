
# CineScope - Movie Search App

CineScope is a simple movie search website where users can search for their favourite movies and view their posters and release years.

## Features

- Search movies by name
- Display movie posters
- Show movie release years
- Open movie details on IMDb
- Simple and responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- OMDb API

## How to Use

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Enter a movie name in the search box.
5. Click the Search button to see the results.

## Project Files

- index.html - Main webpage
- style.css - Website design
- script7.js - Movie search functionality
- OIP.webp - Default movie poster

## API Used

This project uses the OMDb API to search for movie information.

Website: https://www.omdbapi.com/
